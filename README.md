🐍 Python Snake Game

A classic Snake Game built using Python and Pygame. This project helped me practice Python programming, game logic, keyboard event handling, collision detection, and basic game development.

🚀 Features

- Snake movement using keyboard arrow keys.
- Food generation at available grid positions.
- Score increases by 10 points whenever the snake eats food.
- Wall collision detection.
- Self-collision detection.
- Pause and resume functionality using the SPACEBAR.
- Grid-based game design.
- Adjustable snake speed.

🛠️ Technologies Used

- Python 3.12
- Pygame
- Random module

📥 Installation and Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder

cd snake_game

3. Install Pygame

python -m pip install pygame

4. Run the game

python snake_game.py

🎮 Game Controls

Key| Action
↑| Move Up
↓| Move Down
←| Move Left
→| Move Right
SPACEBAR| Pause / Resume
Close Window| Exit Game
